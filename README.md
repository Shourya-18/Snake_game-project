# 🐍 Snake Game

A classic Snake Game built using **HTML, CSS, and JavaScript**.

The player controls a snake, eats food to increase the score, and tries to achieve the highest score without hitting the walls or itself.

## 🎮 Live Demo

[Snake Game](http://127.0.0.1:5593/html/SnakeGame.html)

> Note: This link works only on your local computer while the project is running. For a public demo, deploy the project using GitHub Pages.

## ✨ Features

* Responsive game board
* Snake movement using keyboard controls
* Random food generation
* Snake grows after eating food
* Score and high score tracking
* Game over detection
* Board adjusts to window resizing

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🕹️ How to Play

1. Start the game.
2. Use the arrow keys to move the snake.
3. Eat the food to increase your score.
4. Avoid hitting the walls and yourself.
5. Try to beat your high score!
